# PyTorch 训练工程：七节完整课程

本课程以仓库真实实现为教材，面向“能运行代码，希望理解并独立修改训练工程”的学习者。由原有 Day 0–8、总学习计划和 argparse 加餐重新编排；加入尾窗口修复、工程边界、完整实验和参考答案。公开版本不包含个人环境路径与身份资料。

**七节是七个学习单元，不要求七天读完。** 建议每节分两晚，每晚约 1.5–2 小时：第一晚读原理并运行实验，第二晚读源码、做反证、写复盘。基础薄弱时第一节可多用一晚；时间估计不作为学会的证明。

学习前先看 [技术栈地图](TECH-STACK.md)，区分项目实现证据与自己的掌握程度；按 [学习方法](STUDY-METHOD.md) 选择核心/源码/迁移路径。每节开头的闭卷检查链接到 [54 道面试追问](INTERVIEW.md)，答案默认折叠。七节主题保持不变，新增资料作为练习与导航。

## 使用约定

所有终端命令从仓库根目录运行。`python` 表示你选择的项目解释器，先完成第一节环境检查。命令尽量单行，兼容 PowerShell 与 Bash；环境变量明确分 shell 说明。标注“可运行实验”的 Python 代码块是完整脚本，可保存到 `outputs/course/` 执行；这个目录是个人实验产物，不提交。解释用的短代码只表示局部逻辑。

源码链接按文件定位，函数名作为稳定搜索入口；用 `rg -n 'def train_one_epoch' src/train.py` 查你当前版本的行号。不要照搬旧教程的固定行号。手算与预期行为不是机器基准；历史耗时和显存只在原环境条件下成立。当前教学依据代码版本与文件链接，具体结果由亲手运行确认。

## 每节的学习闭环

1. 合上答案先回答开头的问题；不会的题记下来。
2. 手算最小例子，记录运行前预测。
3. 运行实验，记录命令、环境、配置、预期与实际。
4. 对照源码，确认每一步改变哪个状态。
5. 在独立分支或副本中破坏一个因素，观察测试是否抓到。
6. 恢复源码，检查差异、文件哈希并重新跑判据；基线恢复后再进入下一节。
7. 写 150–300 字复盘：现象、根因、证据、限制。

破坏实验不用删数据、卸载包或改系统配置。一次只改一处；不要把未恢复版本推到主分支。每节都有验收题与参考答案，背答案不算过关。
